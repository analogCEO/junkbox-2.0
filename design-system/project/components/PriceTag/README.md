# PriceTag

A small ink tag with a bite out of its corner, set in Martian Mono. Bulgarian price format: comma decimal, a space, then €.

- **Provide:** the amount as "10,99" and `<small>€</small>`. Always two decimals.
- **Variants:** default follows the theme (`tag` / `on-tag`: ink in Light, cream in Dark). `jb-price--ink` stays ink in both themes; use it on photos and post artwork. `jb-price--amber` for ink grounds. For a combo saving, follow the tag with `<span class="jb-price-was">` holding what the items cost separately.
- **Don't:** write "10.99€", "€10.99" or "10,99лв". Don't colour prices chili; red means heat here.
