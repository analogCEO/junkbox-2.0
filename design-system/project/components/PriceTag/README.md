# PriceTag

A small square tag in Montserrat SemiBold. Bulgarian format: comma decimal, a space, then €.

- **Provide:** the amount as "10,99 €", always with two decimals.
- **Variants:** default follows the theme (`tag` / `on-tag`). `jb-price--amber` on ink grounds; `jb-price--ink` on photos and posts, where the theme shouldn't change it. For a combo saving, follow with `<span class="jb-price-was">` holding what the items cost separately.
- **Don't:** write "10.99€", "€10.99" or "10,99лв".
