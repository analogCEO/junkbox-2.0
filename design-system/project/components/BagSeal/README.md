# BagSeal

The amber sticker that closes every delivery bag. It's the first branded thing a delivery customer touches.

- **Print:** 70 × 100 mm die-cut with the bite, on amber stock or full-bleed amber, ink only. The order rows are thermal-printed onto a blank area, or handwritten.
- **Provide:** order number, item rows with weights, platform and time, and one rotating sign-off line in the brand voice ("Stay strong. Яж топло.", "Combo breaker доставен.", "Без вилица. Без съжаление.").
- **Pair with:** the ink stamp on the kraft bag and box (`junkbox-stamp.svg`). Two inks in total, so packaging stays cheap.
