# BagSeal

The amber sticker that closes every delivery bag: the wordmark and tagline, an order number, and the item list.

- **Print:** 70 × 100 mm on amber stock, ink only. The order rows are thermal-printed or handwritten.
- **Provide:** order number, items with weights, platform and time.
- **Pair with:** `junkbox-icon-ink.svg` as a one-colour stamp or print on kraft bags, boxes and cups.
