# HeatMeter

Three pill segments in `chili` show how hot an item is, from 0 to 3, with a word beside them so heat never depends on colour alone.

- **Provide:** the level (fill that many `<i class="on">`), a word, and an `aria-label` such as "Лютивина 2 от 3".
- **Words:** 0 Без лютивина · 1 Леко · 2 Люто · 3 Bandolero. Level 3 is named after the house hot sauce in the Hot Bandolero burger.
- **Use** on menu cards, printed menus and the "character select" posts. Items at level 2 or 3 also get the ЛЮТО tag.
