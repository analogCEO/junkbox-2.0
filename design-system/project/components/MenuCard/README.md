# MenuCard

One menu item: photo on the amber sweep with a bite out of its corner, then the hero name, the category line, ingredients, weight, heat and price.

- **Provide:** a square photo shot on `amber` (see Photography in the brand book), the item's hero name in English, the Bulgarian category line ("Телешки бургер + картофки"), ingredients as one comma-separated sentence, weight in grams, heat 0 to 3, and the price.
- **Order of tags:** НОВО or КОМБО first, then ВЕДЖИ or ЛЮТО, then weight.
- **Weight is required.** Wild West, Crispy King, Double Cheese-murder and Hot Bandolero have none on Glovo today; the kitchen should weigh them and add it.
- **No photo yet:** leave the amber square empty with "снимка: предстои". Never fill the gap with a stock image.
- **Don't:** put the weight inside the description, wrap the description in slashes, or mix the category into the hero name ("Wild West Бургер + Fries" becomes name "Wild West", category "Телешки бургер + картофки").
