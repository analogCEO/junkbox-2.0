# MenuCard

One menu item: the photo on amber, the name hand-lettered, the category in tracked caps, the ingredients, the weight and the price.

- **Provide:** a square photo shot on `amber`, the item's name, the Bulgarian category line ("Телешки бургер + картофки"), ingredients as one comma-separated sentence, weight in grams and price.
- **No photo yet:** show the logo illustration (`junkbox-icon-ink.svg`) on the amber square, as in the second card. Never use stock photos.
- **Weight is required.** Wild West, Crispy King, Double Cheese-murder and Hot Bandolero have none on Glovo today, which is why the first card has no weight tag.
- **Don't:** put the weight inside the description, wrap descriptions in slashes, or mix languages in the name ("Wild West Бургер + Fries" becomes name Wild West, category "Телешки бургер + картофки").
