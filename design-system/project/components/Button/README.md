# Button

Square-cornered buttons with wide-tracked caps, in the same voice as the logo's tagline.

- **Provide:** `<button class="jb-btn">` with a one- or two-word Bulgarian verb; CSS sets caps and tracking. Add `<span class="jb-btn-price">` to show a price.
- **Variants:** amber (default) for the one main action on a screen (Поръчай, Добави). `jb-btn--ink` for navigation (Виж менюто). `jb-btn--outline` for extras (Добави сос). `disabled` when the kitchen is closed.
- **Don't:** put an amber button on an amber ground; use `jb-btn--ink`. Keep the 3px `focus` ring.
