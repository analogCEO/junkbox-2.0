# Tag

Small labels on menu cards, posts and listings. Five only.

| Class | Text | Meaning |
| --- | --- | --- |
| `jb-tag--new` | НОВО | Added in the last 30 days. Replaces "(Нов)", "(Ново)" and "(NEW)", which are all on Glovo today. |
| `jb-tag--combo` | КОМБО | A menu with two or more mains and drinks. |
| `jb-tag` | ВЕДЖИ | No meat. |
| `jb-tag--hot` | ЛЮТО | Spicy, like Hot Bandolero. The only place `hot` is used. |
| `jb-tag--weight` | 380 г | Portion weight. Every main carries one. |

- **Provide:** a `<span>` with the word; CSS sets the case.
- On delivery apps, where tags can't be styled, start the description with them: "НОВО · 380 г ·".
